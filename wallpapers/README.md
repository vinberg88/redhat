# RHEL 10 wallpapers

Community wallpapers for this RHEL-on-WSL project.

These are unofficial fan wallpapers for **Red Hat Enterprise Linux 10**. They are not official Red Hat brand assets.

| File | Theme |
|---|---|
| `rhel10-blue-yellow.jpg` | Blue background, yellow RHEL 10 |
| `rhel10-yellow-blue.jpg` | Yellow/gold background, blue text |
| `rhel10-forest-yellow.jpg` | Teal forest, yellow title |
| `rhel10-purple-cyan.jpg` | Purple background, cyan + yellow text |
| `rhel10-blue-gold.jpg` | Blue + gold split |

Drop the five JPG files into this folder, then they will show on the main README.
