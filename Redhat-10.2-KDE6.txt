Fix IP problem for X410. Cant find screen problem. Look for ip adress in windows terminal / PowerShell: ipconfig

OPEN POWERSHELL FROM MICROSOFT AND TYPE: ipconfig

NOTE - Importent to look for ip. Last lines are IP-numbers for WSL in POWERSHELL so x410 works.

SAVA IP-ADRESS FROM POWERSHELL HERE: 172.30.16.1

NOW GO BACK TO REDHAT 10.2 Terminal and paste this.

sudo systemctl unmask systemd-resolved.service
sudo systemctl enable systemd-resolved.service

sudo ls -l /etc/resolv.conf
sudo mv /etc/resolv.conf /tmp/resolv.conf.bak
sudo nano /etc/resolv.conf

nameserver 172.30.16.1  <-- put your ip here from POWERSHELL and add nameserver.

sudo chattr +i /etc/resolv.conf
sudo systemctl restart systemd-resolved
sudo cat /etc/resolv.conf

DONE - alot of problem fixed =]

Last step for Red Hat Enterprise Linux 10 — KDE Plasma 6 + X410

The last thing to install is the start script that makes KDE Plasma 6 work with X410 under WSL2.

IMPORTANT!: START X410 XSERVER FOR WINDOWS 11 FIRST.

NOTE: Do not continue until X410 is running.

After X410 has started, open your Red Hat Enterprise Linux 10 terminal and run:

wget -O install-kde6-x410-rhel10.sh \
https://raw.githubusercontent.com/vinberg88/redhat/main/scripts/install-kde6-x410-rhel10.sh

chmod +x install-kde6-x410-rhel10.sh

./install-kde6-x410-rhel10.sh

Now check the installation via terminal:

kde6-x410 doctor

You will see something like this =)
